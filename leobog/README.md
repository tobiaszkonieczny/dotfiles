# leobog - keyboard and mouse dock RGB follow the wallpaper

`leobog-rgb` sets the wallpaper's primary color generated by Noctalia on:

- **LEOBOG Hi75C Pro** keyboard: 2.4 GHz dongle (`3554:fa09`) and USB cable (`258a:010c`)
- **MCHOSE MagDock**, the RGB charging dock of the MCHOSE A7 V2 Pro+ mouse (`3837:1012`)

Every command applies to all connected devices.

## Install

```bash
stow leobog                                         # or pick it in ./install.sh
sudo cp leobog/udev/70-leobog.rules /etc/udev/rules.d/
sudo udevadm control --reload && sudo udevadm trigger
systemctl --user daemon-reload
systemctl --user enable --now leobog-rgb.service
```

The keyboard must be in its **self-define (custom color)** lighting mode. The dock is switched to static mode automatically.

## How it is wired up

| Where | What |
| --- | --- |
| `noctalia/.config/noctalia/config.toml` (`[theme.templates.user.leobog]`) | on every palette change: `leobog-rgb save <primary>` |
| `noctalia/.config/noctalia/templates/leobog-color` | template that outputs the primary color |
| `hypr/.config/hypr/modules/autostart.lua` | restores the last color at login |
| `hypr/.config/hypr/modules/keybindings.lua` | `Super + F11` / `Super + F12`: brightness -10% / +10% |
| `leobog-rgb.service` | `leobog-rgb hold`: re-sends the color every 0.7 s on the cable (live only there), on the dongle only when something changes |

## Usage

```bash
leobog-rgb save '#ff8800'      # set a color (save without a color = restore the last one)
leobog-rgb brightness 30       # percent, also +10 / -10
leobog-rgb config dock_saturation 0.5   # see the config file for all keys
leobog-rgb test ffffff         # calibration color, not stored; back with: leobog-rgb theme
leobog-rgb find                # which device / mode is used
```

Color tuning (gamma, white balance, saturation per device) lives in this module:
`.config/leobog-rgb/config`, stowed to `~/.config/leobog-rgb/config`. Edit it here or with
`leobog-rgb config <key> <value>`. Brightness changes all the time (hotkeys), so it is kept
outside the repo in `~/.local/state/leobog-rgb/brightness`; the last color is in `~/.cache/leobog-rgb/last`.
Colors are converted for LEDs (gamma + brightness) because LEDs are linear and make sRGB colors look whitish.

## Protocol

- Dongle, live color `0x88` (expires after ~1 s): from [x0sman/better-hi75c-pro-driver](https://github.com/x0sman/better-hi75c-pro-driver).
- Dongle, profile `0x02` (kept until the keyboard is powered off): found by testing - 378 bytes planar
  `R[126] G[126] B[126]`, 27 reports `13 02 1b <seq> 0e <14 bytes> <checksum>`.
- MagDock: 64-byte reports `aa <cmd> 00 00 00 <len> <params>`, cmd 7 reads and cmd 39 sets
  the lighting (switch, mode 0 = static, modeNum, speed, brightness 0-4, sync, R, G, B, direction).
  Stored by the dock itself. From the official MCHOSE M HUB web driver.
- Cable: 520-byte feature report `06 08 00 00 00 00 7a 01` + RGB per slot, live only:
  from [pzwt4cc/LEOBOG-GUI-HI75C](https://github.com/pzwt4cc/LEOBOG-GUI-HI75C).

Details are in the header comment of `leobog-rgb`.
